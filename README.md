# Impulse
  Impulse — це сучасний фітнес-трекер, покликаний підвищити мотивацію користувачів віком 18–50 років через усунення складних графіків і заплутаної статистики. Проєкт вирішує проблему низької залученості, замінюючи незрозумілі дані на чіткий та наочний візуальний стимул для відстеження прогресу.
